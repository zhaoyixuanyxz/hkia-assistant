# 新产品需求（Product Requirements）

## 产品名称
**Hong Kong Insurance Agent (HKIA)**  
全香港最顶尖的保险配置智能体

## 产品愿景
构建一款**真正的 AI Agent 产品**，而非传统的保险推荐工具。它能以顶尖保险经纪人的身份，与用户进行自然、深度、长链条式的对话，动态构建高度个性化的用户画像，生成真正定制化的保险配置策略和视觉报告。

核心理念：**“每个用户都应该拥有一个专属的、会思考的保险专家”**。

## 核心需求

### 1. 智能对话系统（核心突破点）
- **完全抛弃固定问答流程**：支持开放式、自然语言、任意顺序的长对话。
- **高温度 Agent**：temperature 0.7-0.9，强调专业性、洞察力、个性化建议、发散性思考。
- **动态用户画像**：不使用固定 JSON 模板。
  - Agent 负责在对话中逐步构建、迭代、完善用户画像。
  - 画像包含结构化数据 + 非结构化记忆 + 向量嵌入。
  - 支持多维度（财务、家庭、健康、风险偏好、人生阶段、价值观等），并能自动发现新维度。
- **记忆系统**：支持长期记忆、实体记忆、对话历史总结。

### 2. 个性化专属报告
- **图表高度定制化**：内置 12+ 种专业金融/保险可视化组件
  - 每份报告自动选择 3-5 种最适合当前用户故事的图表。
  - 图表风格、颜色、叙事逻辑完全根据用户画像定制（非模板化）。
- **推荐产品**：不再限制为 3 个。
  - 推荐 5-10 个（或更多）不同类型的产品（储蓄型、医疗、重疾、寿险、危疾、投资连结、年金、海外保险等）。
  - 每个产品包含精确官网链接（解决历史跳转问题）。
- **报告叙事**：像顶尖顾问一样撰写故事，而非列表。包含情景模拟、敏感性分析、长期轨迹预测。

### 3. 香港保险知识库（核心基础设施）
- **功能**：取代原管理员页面。
- **内容**：收录中国人寿海外保险公司所有公开保险产品。
- **结构化维度**：
  - 所属保险公司
  - 产品类别（储蓄、保障、医疗、重疾、危疾、年金、投资连结等）
  - 主要特点、保障范围、保费示例、目标人群、关键条款
  - 精确产品官网链接（必须可直接跳转到产品页）
  - 最后更新时间、数据来源
- **特性**：
  - 支持全文搜索 + 向量语义搜索
  - 定时自动爬取更新（或手动一键触发）
  - 管理员可审核、补充、标记过时产品

### 4. 市场情报模块
- **数据类型**：宏观经济指标、汇率、香港保险行业趋势、监管政策、健康人口统计、ESG、地缘政治影响等。
- **核心功能**：
  - **一键更新按钮**：手动触发最新数据爬取、解析、存储、图表渲染。
  - **精确数据源跳转**：每个指标必须链接到具体数据来源页面，而非官网首页。
  - 数据新鲜度显示 + 更新历史。
- **可视化**：动态、专业级图表。

### 5. 前端视觉与体验
- **现代金融 Agent UI**：深色专业主题、高级排版、流畅动画、响应式设计。
- **对话界面**：类似 ChatGPT 但更金融专业（侧边栏画像预览、实时进度、记忆卡片）。
- **报告页面**：叙事驱动 + 可交互图表 + PDF/打印导出。
- **知识库页面**：强大搜索 + 过滤 + 卡片/表格双视图。
- **使用 shadcn/ui + Tailwind + 高级图表库** 实现独特视觉身份（调用 frontend-design skill）。

## 非功能需求
- **合规性**：强 Disclaimer，所有输出必须声明“非持牌财务/保险建议，仅供参考”。
- **性能**：对话响应 < 3s，报告生成 < 15s。
- **可扩展性**：易于添加新 Agent、 新图表类型、新数据源。
- **安全性**：用户数据加密、API 密钥管理、爬虫合规。
- **多语言**：优先中文（繁体/简体），支持英文。

## 成功指标
- 用户能进行 10+ 轮自然对话而不觉得“被引导”。
- 每份报告图表和推荐产品都有明显个性化差异。
- 知识库覆盖香港主流 90%+ 公开保险产品，且链接可用。
- 市场数据可每日更新且来源精确。
