# Design: US-5 保额、保费、摘录日期按月自动入库

## Goal

香港时区进入新的公历月时，一轮进程内循环自动抓取中国人寿海外官网产品页，把保额、保费、摘录日期写入产品库。操作者不用手动调试或当场补数。对照 `docs/2026-10-22-用户故事-保额保费摘录日期.md` 的 US-5。

## Decisions locked in design review

- 页面没有单一保额或单一保费：这两项留空，来源记录写「页面没有单一数字」，不编造。其他产品照常写入。
- 做法：按月一整批，自己写循环。不点名编排引擎。不做 MCP。不把现有手跑摘要脚本当作本路径。
- 过期按月、报告门禁是 US-2 / US-3；失败后整月再跑是 US-6。本规格不实现它们。

## Architecture

一轮按月循环，批处理，不是可恢复的长流程。不等人审批。

外部端口：

- 中国人寿海外官网产品页（只读，只许这个来源）
- 产品库（写入保额、保费、摘录日期）

留在进程里：打开页面、判断是否单一数字、把摘录日期落到抓取所在公历月、写库。

沿用现有表，不新造编排服务：

- `products`：增加三个可空列，字段名固定为 `sum_assured`（保额）、`premium`（保费）、`excerpt_date`（摘录日期，必须能落到公历月）
- `product_sources`：记这一次抓取的来源 URL、原始摘录要点、以及「页面没有单一数字」标记
- `data_update_jobs`：记这一轮的开始、结束、成功或失败；不记「从哪一条产品接着跑」

免责声明、四条边界（不承保、不代替持牌人签字、不做中国人寿海外以外的公司、不收保费），以及「第一次会见拿出 3 个方案」，本规格一字不改。

## Components and data flow

同一条循环按顺序：

1. **列产品页**：只取中国人寿海外官网已有产品页 URL，不扫其他公司。
2. **抓并抽**：打开该页。若有单一保额、单一保费则写入对应位置；若无，两项留空，来源记录写「页面没有单一数字」。
3. **落月**：本路径写入的 `excerpt_date` 一律取这一轮启动时刻所在的香港时区公历月（存成该月内可比较的日期，例如该月 1 日，或同等能落到月的表示）。本路径不会写出落不到月的值。
4. **写库**：更新该产品的 `sum_assured`、`premium`、`excerpt_date`；写一条 `product_sources`；整轮结束后更新 `data_update_jobs`。

「当月已自动更新」的含义：该月写入可追溯到这一轮自动抓取，而不是操作者手改或手跑摘要脚本。

## Error handling

| 情况 | 行为 |
|------|------|
| 任一产品页请求失败，或进程在轮次中异常退出 | `data_update_jobs` 记失败。不从断掉的那条接着写（US-6）。不编造数字，不用手改顶上。本轮已成功写入的产品保留当次值（下次整月再跑时幂等覆盖）；不维护「下一产品」游标。 |
| 某一页没有单一保额或单一保费 | 该产品 `sum_assured`、`premium` 留空并记下；其他产品照常写。不算整轮失败。 |
| 出现非中国人寿海外的 URL | 丢弃，不入库。 |
| 读库时发现历史 `excerpt_date` 落不到公历月 | 不得当作当月已更新；停下来问操作者。本路径自己写入时不会制造这种情况。 |

## Out of scope (this row)

- US-1 三列报告版式
- US-2 / US-3 报告门禁与过月过滤
- US-4 报告值与库一致的生成侧验收（本规格只负责写入）
- US-6 失败后整月再跑的续跑语义（本规格已约定不接着写；续跑产品行为归 US-6）
- US-7 对外说法与免责声明文案变更
- 保额、保费与条款原文数字是否一致
- MCP、SLO、产品度量、A/B

## Acceptance (maps to US-5)

1. 产品库记录上能读到保额、保费、摘录日期三个位置。
2. 某公历月跑完后，该月写入可追溯到自动抓取；操作者未手动调试或当场补数。
3. 入库来源只有中国人寿海外官网产品页。
4. 只有旧手跑摘要脚本（如 `scripts/discover_chinalife_product_urls.py`、`scripts/build_chinalife_product_seed.py`）的产出，不算本行通过。

产品经理对照 US-5 的 Given/When/Then 验收。

## Testing notes

- 有单一数字的样例页：三字段写入，摘录月为跑轮所在香港时区公历月。
- 无单一数字的样例页：保额、保费为空，来源含「页面没有单一数字」，整轮仍可成功。
- 非法来源 URL：不入库。
- 中途失败：job 为失败；库中不得出现「半截接着写」的进度依赖（与 US-6 衔接）。
- 不得以手跑摘要脚本的输出冒充本行通过。
